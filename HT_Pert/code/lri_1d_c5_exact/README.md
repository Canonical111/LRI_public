# lri_1d_c5_exact — exact finite-cutoff C5(Λ) of the d = 1 LRI Hamiltonian truncation

Plan, acceptance criteria and method: `PLAN.md` (Codex-approved, sha256 eebfc3c3…); review and inspection log
`PLAN-REVIEW-LOG.md`; module interfaces `INTERFACES.md`. The method extends `../lri_1d_c4_exact` (C4P) to fifth order:
the RS assembly is generated by `rs5.py` (2D `rs.py`, vendored verbatim), the four-slice densities use the middle-split
five-vertex kernel (`lib5/kernel5.py`), and the Dconn window at ε⁵ is assembled in `windows5.py`.

| file | role |
|---|---|
| `lib5/` | engine: series and two-ended ε-jets (`series.py`), zero-mode paths (`paths.py`), even-parity densities with Leibniz jet terms and empty-slice factorisation (`density.py`), five-vertex streaming kernel (`kernel5.py`), shells (`shells.py`), exact per-key functionals (`keys.py`) |
| `words5.py`, `assemble5.py` | canonical RS chains (89 at order 5) and the assembly of r2..r5, g2..g5, C2..C5, per-p X_p, ε⁵ vacuum windows |

| `fits/` | A8: `fits_c5_1d.py` (freeze/compare/check/explore + ω3 diagnostic), `tail_fixedA_c5.py` (fixed-intercept tail fits), `frozen/`, `explore/`, blind-check records |
| `slurm/` | symmetry layer: `env.sh`, `validate.slurm`, `bench.slurm`, `node.slurm`, `assemble.slurm`, `submit.sh`, `README_SLURM.md` |

## A8 analysis
**Blind check** (`fits/blind_check_L320_to_400.txt`): fits frozen from the L320 result (commit 6e15b08, written before
the L400 data existed) predict C5Dconn(Λ) for 320 < Λ ≤ 400 to 1.0e-9 (L2, lo 80), 2.1e-9 (M3), 4.2e-9 (M3x); L1 is off
by 2e-7–5e-6, P6 by 4e-6–2e-3, P4 by 2e-4–4e-2. Raw scheme: same numbers. Fits frozen from L400 (predicting to 500) are
in `fits/frozen/frozen_L400_*.json`.

**Intercepts.** Free-intercept fits extrapolate C5Dconn(∞) only to a few tenths: L2 (no log³) gives −730.85 (lo 80–160,
stable to 0.1) = C5 + 0.29; M3 gives −731.08 (lo 80) but becomes unstable above lo 120 (cond ≥ 1e16 against the 1e-11
noise). Fixed-intercept fits (`fits/explore/L400/tailA_*.log`) settle it: with A = C5 the L2 basis leaves a 5e-10
residual at lo 80 (its profile minimum is at A = C5 + 0.3), while M3 (adds Λ^{-1/2} log³ Λ) fits at the noise floor
(1.5e-11) and its residual profile is flat for |A − C5| ≲ 0.3. So the data are consistent with C5Dconn(∞) = C5 at the
±0.3 level, and the log³ term is required.

**Tail.** M3 with A = C5: Λ^{-1/2}(c10 + c11 log Λ + c12 log² Λ + c13 log³ Λ) with c13 = 1.967 (lo 80), 2.004 (lo 120);
c12 = 45.9 / 44.4; c11 = 312 / 335; c10 = 443 / 319 (lo 160 and M3x are unstable). The top log agrees with the
exponentiation of the C4 tail: c13 = −(w1/3) c12^(C4) with w1 = 7/2 (the joint thermal model weight) and the C4P
refit c12^(C4) = −1.715 (lo 200) / −1.697 (lo 400) gives 2.000 / 1.980.

**Window.** ΔC5 = C5Dconn − C5raw tends to a constant ≈ 0.72 (fits give 0.71–0.73 with at most a tiny log Λ term,
|coefficient| ≲ 1e-3): T1 (−0.1216 log Λ) and T2 (+0.1243 log Λ) nearly cancel, T3 and T4 likewise. The raw scheme
therefore converges to ≈ C5 − 0.72.

**ω3 diagnostic** (raw scheme, frozen L320 record): ω3_eff = 486–616 across the joint models A/D/E and lo 80–160
(reference 556.21; model D lo 120 gives 557.46), with intercepts −735.4…−735.8 and condition numbers 3e7–2e13. No
determination of ω3 at this cutoff range.

### Constrained extrapolation: log³ coefficient from the exponentiated tail (2026-10-13)
`fits/constrained_c5.py` (job 574283; records `fits/explore/constrained_L500/`). Hypothesis H: the Λ^{-1/2} tail is
a(ε) Λ^{-ω(ε)}, ω = 1/2 + (7/2)ε + …, so the top log at order n is c_n = a2 (−7/2)^{n−2}/(n−2)!. Here ω(ε) = Δ_{φ⁶} − d of
the leading irrelevant operator (ω1 = −6/4 + 15/3 = 7/2), and a2 = −40/(81√π) from the C2 shell identity
(independent derivation, `xchk/REPORT_theory.md`). The lower-order tests use C4P data to Λ = 2000 with exact intercepts:
c2 = −0.2786121 (= a2); c3 = 0.9751476 vs −(7/2)c2 = 0.9751423 (ratio 1.000005; blind reimplementation 1.0000000(2));
c4 = −1.7113 (well-conditioned fits −1.7039…−1.7125; blind −1.7112(5) in "sparse" bases) vs H −1.70650. The C4 top log
fits about 0.28% off H, depending on the basis. Fixing it at the H value still leaves residuals at the floor (theory
check), so the test is not decisive at ε⁴. With c13 = −(7/2)/3 · c4 = 1.9965 ± 0.0056 (the closed form gives 1.990916;
the C5 intercept moves by ≤ 0.0013 between the two), free-intercept fits of C5Dconn(Λ) − c13 Λ^{-1/2}log³Λ (Λ ≤ 500) give
−731.1467 / −731.1397 / −731.1157 (minimal basis, lo 80/120/160) and −731.1359 (one more column, lo 80); bases with
condition numbers ≥ 1e15 are unstable. The blind reimplementation (`xchk/REPORT_blind.md`, jobs 574286/574292/574295)
gives C5 = −731.13 ± 0.10 (basis A, lo 50–80, error from the spread of all structure-consistent floor-level fits). The
known five-loop C5 = −731.1394766: the constraint improves the extrapolation from ±0.3 to ≲ ±0.1 (best fits within 0.01).
Caveats: the thresholds of `constrained_c5.py` were set after its first run had printed the known C5 (NOTE.txt). The
blind agent's memory index also showed the earlier numerical c5, so neither estimate is strictly blind. Λ^0 log Λ in
Dconn is assumed absent (as at ε⁴); ΔC5 carries ≈ 5e-4 log Λ, i.e. in the raw scheme.

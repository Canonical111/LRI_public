# HT_Pert note: perturbative Hamiltonian truncation of the long-range Ising model

`lri_ht_perturbative.pdf` and its TeX sources. The note covers the frozen-cutoff perturbative HT in d = 1, 2, 3: the
model and cutoffs, Rayleigh–Schrödinger perturbation theory at fixed cutoff, the large-cutoff tails, the vacuum-window
corrections, every quoted result (finite-cutoff coefficients C2..C8, window corrections, extrapolations, exact sums
over intermediate states) with its status word, the independent checks, the caveats, and a reproduction section that
maps each number to `HT_Pert/code/<package>`, `HT_Pert/data/HT_<d>d`, `HT_Pert/results/HT_<d>d`, its replay row and
tolerance. Appendices A to C give the d = 2 derivations and supporting data; this is the only TeX note of `HT_Pert/`. The
finite-coupling truncation is documented in `HT/`.

## Files
| Path | Content |
|---|---|
| `lri_ht_perturbative.tex`, `sections/` | the note; `sections/d2/` and `sections/d3/` are the d = 2 and d = 3 contributions |
| `numbers_d1.tex` | the d = 1 macros, generated by `tools/gen_numbers_d1.py` from `data/quoted_numbers_d1.json` (a copy of `HT_Pert/results/HT_1d/quoted_numbers.json`, the expectation file of the d = 1 replays) |
| `sections/repro_d1.tex` | the d = 1 rows of the reproduction table, generated by `tools/gen_repro_d1.py` from the same file and the reader-facing labels in `tools/repro_labels_d1.py` (integrity rows merged into one row per package) |
| `sections/d2/numbers_d2.tex`, `sections/d3/numbers_d3.tex` | the d = 2 and d = 3 macros (paper macros keep the paper's names and values) |
| `sections/d2/{checks,caveats}_d2.tex`, `sections/d3/{checks,caveats}_d3.tex` | the d = 2 and d = 3 paragraphs of the checks and caveats sections |
| `sections/d2/app_d2_{eps4,eps5,legs}.tex` | the d = 2 appendices: operators, exact fourth order and the complete window; order ε⁵; descendant spacings and the external-line windows (merged 2026-10-16 from the former separate method write-up of `lri_2d_coeff_independent_check`, which no longer ships) |
| `tools/check_note.py` | read-only check: the generated files are current and, inside the public tree, the data file equals `HT_Pert/results/HT_1d/quoted_numbers.json`; `--checksums` verifies `MANIFEST.json` |

## Build and check
```
make          # latexmk -pdf (TeX Live 2021 or later: amsmath, amssymb, booktabs, graphicx, longtable, array, xcolor, hyperref, microtype)
make check    # python3 -B tools/check_note.py --checksums
```

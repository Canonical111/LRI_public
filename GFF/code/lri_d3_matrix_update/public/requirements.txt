# Python requirements of lri_d3_matrix_update (pip install -r public/requirements.txt).
# The package README asks only for Python 3, mpmath and SymPy and records no versions for the rank-two scripts; the
# inherited verification/general_d3/environment.json of the same tree records Python 3.13.5 and mpmath 1.3.0. The public replay was tested on 2026-10-13 with Python 3.10.12,
# mpmath 1.3.0 (gmpy2 backend) and SymPy 1.12: every rerun record was bitwise equal to the shipped one.
# Keep mpmath at 1.3.0: the comparison tolerances allow a different last guard digit, but a different mpmath release may
# change its series and quadrature defaults.
mpmath==1.3.0
sympy>=1.12

# C6(1): lower-degree parameters for the five seventh-sector values

## Result and scope

Input: `C6_five_seventh_values_expression.json`. The input has twelve fixed
special-function values and no explicit residual sum or integral in the active
coefficient. Five of those values are Kampé de Fériet functions with local
orders 26/25 and sixteen polynomial-root parameters per shift.

This calculation keeps the same twelve-value count but replaces those five
functions by `F_{18:0;3}^{18:1;4}` values, with ten root parameters per shift.
The roots move to the shared parameter lists. Uniform list entries per value
fall from 68 to 44 before optional cancellations; eighty listed roots fall
to fifty. The local lists return to orders 4/3.

This is an exact representation transformation, not an elementary evaluation,
a theorem about independent periods, or an optimality claim. There is a
numerical cost: the absolute total-index diagonal decreases as
`log(k)/k^(3/2)`, rather than the old `log(k)/k^(5/2)`. Both converge absolutely.

All other function definitions, the eighteen-monomial known polynomial,
normalizations, source correction, and prior physical graph/RG identifications
are inherited and preserved. No full-coefficient or special-value numerical
interval certificate is constructed here.

## 1. The inherited seventh-sector target

For each r in {1,2,3,5,7}, let
\[
t=r/8,\quad a=t+1/4,\quad b=t+3/4,\quad c=t+1/2,
\]
and let p_r,b_r be the saved finite weights. Put xi_r=b_r/(98 p_r).
The single-shift target, before its fixed-function conversion, is
\[
T_r=\sum_{n\ge0}u_n(H_n+\xi_r),\qquad
u_n=(-1)^n(n+t)\left[\frac{\Gamma(n+a)}{\Gamma(n+b)}\right]^7,
\]
\[
h(n)=\frac{n+c}{(n+a)(n+b)},\qquad H_n=\sum_{j=0}^{n-1}h(j),\quad H_0=0.
\]
The full contribution to r6=2187 C6 is
\[
B_7=9408\pi^{3/2}\sum_{r\in\{1,2,3,5,7\}}p_r T_r.
\]
The input's latest five-function form is T_r=-Omega_r K_r. We start instead
from this already retained target so that the ordinary n=0 contribution is
tracked explicitly. All infinite sums in this proof are intermediate, not
new residuals in the final coefficient.

## 2. Abel summation moves the rational correction to the shared coefficient

Define
\[
V_n=u_n\left(\frac{\xi_r}{h(n)}-1\right),\qquad
w_n=u_n+V_n-V_{n+1}.
\]
For every positive integer N, direct finite summation by parts gives
\[
\boxed{
\sum_{n=0}^{N-1}u_n(H_n+\xi_r)
-
\sum_{n=0}^{N-1}w_nH_{n+1}
=V_NH_N.}
\tag{1}
\]
Indeed, H_(n+1)-H_n=h(n), including H_1=h(0). Thus
\[
\sum_{n=0}^{N-1}(V_n-V_{n+1})H_{n+1}
=\sum_{n=0}^{N-1}V_nh(n)-V_NH_N.
\]
There is no lower boundary term to append: V_0 H_1 is already part of the
finite identity. Since u_n=O(n^(-5/2)), h(n)=1/n+O(n^(-2)), and
H_n=log n+O(1), one has
\[
V_NH_N=O(N^{-3/2}\log N)\longrightarrow0.
\]
Consequently
\[
\boxed{T_r=\sum_{n\ge0}w_nH_{n+1}.}\tag{2}
\]
This differs from the previous construction, which kept u_n fixed and changed
the local increment h(j). Here h(j) is unchanged and the shared coefficient
u_n is transformed to w_n.

## 3. A degree-ten polynomial specifies the new shared parameters

Suppress the subscript r temporarily. Define the explicit polynomial
\[
\boxed{\begin{aligned}
\widetilde P_r(x)={}&
\xi_r(x+t)(x+b)^8(x+c+1)\\
&+(x+t+1)(x+a)^6(x+c)
\left[\xi_r(x+a+1)(x+b+1)-(x+c+1)\right].
\end{aligned}}
\tag{3}
\]
Its degree is ten and its leading coefficient is 2 xi_r. It is not the
old monic degree-sixteen polynomial, and its roots must not be reused from
the old representation. Define the unordered ten-member root multiset by
\[
\widetilde P_r(x)=2\xi_r\prod_{j=1}^{10}(x+\gamma_{r,j}).\tag{4}
\]
The parameters are algebraic over the field generated by the explicit xi_r;
we do not claim that they are algebraic over the rationals.

Gamma recurrence gives
\[
\frac{u_{n+1}}{u_n}=-\frac{n+t+1}{n+t}
\left(\frac{n+a}{n+b}\right)^7.
\]
Substitution in the definition of w_n and exact cancellation yield
\[
\boxed{
w_n=(-1)^n\left[\frac{\Gamma(n+a)}{\Gamma(n+b)}\right]^7
\frac{(n+a)\widetilde P_r(n)}
{(n+c)(n+c+1)(n+b)^7}.}
\tag{5}
\]
The factor n+a has been removed from the degree-eleven numerator before
forming (3), which explains one of the parameter cancellations.

For the normalized shared coefficient S_n=(-1)^n w_n/w_0,
\[
\boxed{
S_n=
\frac{(a)_n^6(a+1)_n(c)_n}
{(b+1)_n^7(c+2)_n}
\prod_{j=1}^{10}\frac{(1+\gamma_{r,j})_n}{(\gamma_{r,j})_n}.}
\tag{6}
\]
The local increment remains
\[
\frac{h(j)}{h(0)}=
\frac{(c+1)_j(a)_j(b)_j}{(c)_j(a+1)_j(b+1)_j}.\tag{7}
\]
All statements (3), (5), and the rational coefficient ratios associated with
(6)-(7) are checked exactly, with xi left symbolic.

## 4. The new fixed special-function values and full substitution

In the classical complex-variable Kampé de Fériet convention [1], define
\[
\boxed{
\widehat{\mathcal K}_r=
F_{18:0;3}^{18:1;4}\!\left[
\begin{matrix}
a^{[6]},a+1,c,1+\boldsymbol\gamma_r:
1;
1,c+1,a,b\\
(b+1)^{[7]},c+2,\boldsymbol\gamma_r:
-;
c,a+1,b+1
\end{matrix};-1,-1\right].}
\tag{8}
\]
Repeated-list notation and list addition are componentwise. The local x
coefficient is (1)_m/m!=1. The local y coefficient includes (1)_j/j!=1.
Thus the coefficient on total diagonal n=m+j is exactly S_n h(j)/h(0).

The finite prefactor is
\[
\boxed{
\widehat\Omega_r=h(0)w_0
=\left[\frac{\Gamma(a)}{\Gamma(b)}\right]^7
\frac{\widetilde P_r(0)}{(c+1)b^8}.}
\tag{9}
\]
Equations (2), (6), and (7), with n=m+j, prove
\[
\boxed{T_r=\widehat\Omega_r\widehat{\mathcal K}_r
=-\Omega_r\mathcal K_r.}\tag{10}
\]
Therefore
\[
\boxed{B_7=9408\pi^{3/2}
\sum_{r\in\{1,2,3,5,7\}}
 p_r\widehat\Omega_r\widehat{\mathcal K}_r.}\tag{11}
\]
The sum in (11) has five terms. The PLUS sign differs from the old
`-9408` form because the signed prefactor has changed; it does not alter the
actual seventh-sector value. No gamma-valued lower-boundary constant or
polynomial compensation is introduced.

The full coefficient is
\[
\boxed{\begin{aligned}
2187 C_6(1)={}&E+B_{\rm pol}+B_{\rm low}+B_6+B_8
-393\pi\sqrt{89}\,\mathcal H_W\\
&+9408\pi^{3/2}\sum_{r\in\{1,2,3,5,7\}}
 p_r\widehat\Omega_r\widehat{\mathcal K}_r
+7680\pi^3\mathcal H_*.
\end{aligned}}
\tag{12}
\]
Every unchanged block, the complete polynomial, and all parameter conventions
are reproduced in FORMULA.md and updated_expression.json. There are twelve
fixed values: two multiple polylogarithms, three ordinary Meijer G values,
five Kampé de Fériet values, and two bivariate H values.

## 5. All lower parameters are admissible

Exact rational enclosures constructed from Machin's arctangent identity,
a positive atanh series for log(2), and an integer square-root bracket give
\[
\xi_1,\xi_2,\xi_3,\xi_5<0,\qquad \xi_7>1.
\]
The approximate values, for orientation only, are
-0.487333, -0.387024, -0.574340, -3.241007, 4.312667.
The exact rational endpoints appear in parameter_admissibility.json.

For real x>=0, all factors x+a, x+b, x+c, x+t and their displayed positive
shifts are strictly positive. If xi<0 both summands in (3) are negative.
If xi>1, note that
\[
h(x+1)=\frac12\left[\frac1{x+a+1}+\frac1{x+b+1}\right]<1.
\]
Then the square bracket in (3) is positive, and both summands are positive.
Hence the polynomial has NO nonnegative real root for any of the five shifts.
In particular P(0) != 0 and none of the gamma_(r,j) is a nonpositive integer.
All other lower parameters in (8) are positive rationals. No limiting or
regularization prescription is needed. The normalized shared coefficients
in (6) are positive at every nonnegative integer n, even when root parameters
are complex, because P(n)/P(0)>0.

## 6. Absolute convergence and the numerical tradeoff

From (5), w_n=2 xi_r (-1)^n n^(-3/2)(1+O(n^(-1))). Also H_(n+1)=log n+O(1).
The absolute n-th diagonal of (8) is consequently
\[
O(\log(n+2)/(n+1)^{3/2}),
\]
which is summable. The original target has absolute term bound
O(log(n+2)/(n+1)^(5/2)). These gamma-ratio exponents follow from [3].
Thus all sums in the proof are legitimate absolutely convergent sums, but
literal diagonal summation of the new function is slower by a power of n.
The old numerical evaluators remain preferable in some settings.

This convergence cost is not hidden by the parameter count: this is an
alternative with simpler finite parameter data, not a universally faster or
minimal representation.

## 7. Executed checks

`build_and_verify.py` passes 127 finite exact checks. Most are coefficient or
finite-boundary checks, not 127 independent theorems. They include:

- the generic degree-ten polynomial identity and gamma-prefactor normalization;
- finite Abel identities for N=1,...,12 and all five shifts, xi still symbolic;
- shared and local Pochhammer-ratio identities;
- full weighted coefficient comparison with the supplied expression;
- exact interval signs needed for admissible lower parameters;
- preservation of the known polynomial, source repair, and all other blocks.

`numerical.py` evaluates three coefficient constructions separately: the old
shifted harmonic series u_n(H_n+xi), the preceding degree-sixteen KdF
diagonals, and the NEW shared-ratio KdF diagonals from (6). Finite Euler
approximants are used only for these implementation checks, not as closed
forms. Runs at (N,digits)=(280,120) and (420,170) give complete old/new seventh-
block residuals about 6.90e-78 and 5.21e-120, respectively. The new sector is
\[
B_7=-11409730.02189293040856018259030951811363354779663422666\ldots.
\]
These are FLOATING-POINT checks, not certified errors or interval enclosures.
The new evaluator has no newly proved explicit Euler truncation certificate.

`check_roots.py` solves all five degree-ten polynomials at 110 working digits
and checks root-based Pochhammer products at n=0,1,2,7,20,75. The largest
relative coefficient discrepancy is below 4.16e-110. This is separate from
the exact nonsingularity proof of section 5, which does not rely on root samples.

No new all-sector C6 evaluation, physical graph/RG proof, or Wolfram kernel
execution was performed. The unchanged wheel certificate has its existing
wheel-only scope.

## Reproduction

Python 3, SymPy and mpmath suffice. From the package directory run:
```
python build_and_verify.py
python numerical.py 280 120
python numerical.py 420 170
python check_roots.py
```
The source expression is retained in inputs/ with its SHA-256 hash in the
updated JSON. Each script records its output rather than silently assigning
saved numerical target values.

# Nine-value C6 representation

Read FORMULA.md for the complete finite expression and DERIVATION.md for the new
seventh-sector proof and limitations. The unchanged input and central-series
source are under inputs/. Run build_and_verify.py for the exact finite checks.
Run numerical.py 45, numerical.py 80, check_inner.py, then check_shifted.py for
the recorded numerical routes. Numerical quadrature is not interval certified.
The special-function expression contains no explicit integration/summation
operator; the numerical scripts evaluate the named values through proved
representations. This package does not independently derive the physical graph
coefficient or certify the complete C6 value.

# Instructions for AI agents

You are reproducing results of a physics study. Follow these rules.

1. **Start from `RESULTS_INDEX.md`.** Each number there names its folder, the command that produces it, the expected value and the tolerance. Do not reproduce a number that is marked superseded.
2. **Work inside one folder at a time** and follow its `REPRODUCE.md` in order: environment, `make test`, `make replay`, the small validation run, then production. Do not skip the validation run before using cluster time.
3. **Do not change the rules.** Fitting protocols, acceptance rules, reporting allowances and tolerances are part of the result. They are listed in each `REPRODUCE.md` under "Decisions you must not make". If a step seems to require changing one, stop and report.
4. **Report, do not repair.** If a replay or a rerun disagrees with the expected value beyond its tolerance, report the numbers and the command; do not edit code or data to make it agree.
5. **Compute.** Production runs need a Slurm cluster; the templates, with placeholders for partition, account and paths, are in the folder's `slurm/` or in each package (`code/<package>/slurm/` or `code/<package>/public/slurm/`), as its `REPRODUCE.md` says. The measured cost of each stage is in `REPRODUCE.md`. Ask before spending more than the stated cost.
6. **Status words matter.** FINAL, INTERIM, PROVISIONAL, CONDITIONAL, NOT REPRODUCED and similar labels in the notes and the index are part of the result; keep them in anything you write.
7. **Placeholders in paths.** In files that are not hash-bound, the authors' machine paths and names are replaced by tokens: `<HOME>` (a home directory), `<SCRATCH>` (cluster scratch), `<PROJECTS>` (cluster project space), `<PROJECT>` (the authors' working folder), `<PAPER>` (the paper's source folder), `<DATA>` (a local data disk), `<USER>`, `<ACCOUNT>` (allocation), `<NODE>` (a compute node) and `<TMP>` (an agent session's temporary folder); the authors' personal machines appear as "personal desktop" (only the symmetry cluster and SDSC Expanse are named); NRG node names are `amd-1` … `amd-9`. Records that are hash-bound keep the original paths byte for byte. Both kinds describe where the production ran: they are history, not paths to use. Run everything from the folder you are in with relative paths, and put your own values only into the Slurm templates.

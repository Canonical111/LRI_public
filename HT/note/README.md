# HT note: finite-coupling Hamiltonian truncation of the long-range Ising model

`lri_ht_finite_coupling.pdf` and its TeX sources. The note covers the method (model, zero mode and bath, density
zero-mode basis, window correction), the extrapolation protocol, every quoted finite-coupling result in d = 1, 2, 3
with its status word, the independent checks, the caveats, and a reproduction section (Section 9) that maps each
number to `HT/code/<package>`, `HT/data/HT_<d>d`, `HT/results/HT_<d>d`, its replay command and tolerance.

The perturbative HT coefficients C2..C8 are documented in `HT_Pert/`.

## Files

| Path | Content |
|---|---|
| `lri_ht_finite_coupling.tex`, `sections/` | the note. `sections/d2/` and `sections/d3/` are the d = 2 and d = 3 contributions. |
| `numbers_d1.tex` | every d = 1 number, generated by `tools/gen_numbers_d1.py` from `data/quoted_numbers_d1.json` (a copy of `HT/results/HT_1d/quoted_numbers.json`, which the d = 1 replay checks) |
| `sections/repro_d1.tex` | d = 1 rows of the reproduction table, generated by `tools/gen_repro_d1.py` from the same file |
| `sections/tab_d1_*.tex` | table rows written by `HT/code/lri_dressed_phi4_hpc_analysis/public/make_tables_ht1d.py`; the replay regenerates them |
| `figures/fig_d1_cutoff.pdf` | made by `tools/make_fig_d1.py` from `data/dens_v1_series.json` (extracted by `tools/extract_series_d1.py`) |
| `sections/d2/tab_d2_values.tex`, `sections/d2/fig_d2_DeltaE.pdf` | made by `tools/make_d2_note_inputs.py` from `HT/results/HT_2d/prod1/points.csv` |
| `tools/check_note.py` | checks that the generated files are current and, inside the public tree, equal to `HT/results/HT_1d` |

## Build and check

```
make          # latexmk -pdf (TeX Live 2023 or later; amsmath, booktabs, graphicx, longtable, hyperref, microtype)
make check    # python3 tools/check_note.py
```

# Data: Resummation

Everything `test`, `replay` and `replay-full` need is in this folder (about 54 MB unpacked, 16 MB packed); nothing is
hosted. `data/inputs/` holds byte-identical copies of the published files of HT, NRG and MC that the comparison and the
derived tables use, and the 2026-10-12 extraction of published 2d/3d MC values (no sibling folder; sources cited per row).
`INPUTS.json` also lists the values embedded in the shipped inputs and code (GFF coefficients C2..C8 in d = 1, 2, 3, the
short-range data) with the file and pointer where the sibling folder publishes them; `make check-inputs` compares them
(the short-range data against SRI/results/sr_values.json and the SRI records; the literature extraction has no sibling
folder: SKIP with citation). Not shipped: version history, internal notes and logs, the previous-C8(1)
outputs (regenerated by `LRI_C8_1=previous`), the 2d/3d notes and their QA (see each package's DATA file).
